# v0.8.2 · DSH 终末地推理滑条

首次 GitHub 分发，面向 Windows 桌面端 DSH Web；已在 DSH 0.2.1-rc.2 验证。

- 模型与推理等级面板，连续拖动、最近档吸附和逐模型记忆。
- 终末地风格按钮、黑黄粒子转场、输入框装饰与发送反馈。
- 修正打开面板时临时滚动条造成的位移问题。

## 下载与安装

普通用户下载 `dsh-endfield-reasoning-slider-0.8.2.zip`，解压后运行 `install.cmd`，安装完成后刷新 DSH Web。需要 Node.js 22 或更高版本，安装目录需保留。

源码开发使用 `dsh-endfield-reasoning-slider-0.8.2-source.zip`。两个 ZIP 的 SHA-256 值见 `SHA256SUMS.txt`。

自定义 profile、卸载和兼容边界详见 README。项目与鹰角网络、《明日方舟：终末地》无官方关联。
